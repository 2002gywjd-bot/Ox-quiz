# 🎮 우리반 실시간 OX 퀴즈

선생님이 방을 열고, 학생은 **링크나 QR 코드로 바로 입장**하는 실시간 OX 퀴즈 웹앱입니다.
설치도, 회원가입도, 서버 로그인도 필요 없어요.

- 👩‍🏫 **선생님**: 방 코드(4자리) + QR 생성 → 문제 출제 → 정답 공개 → 순위표
- 🙋 **학생**: 이름과 사람 캐릭터를 고르고 입장 → 무대에서 화면을 누르거나 끌어 이동
  - 🎨 **캐릭터 꾸미기**: 머리부터 신발까지 나오는 전신 캐릭터. 표정 8 · 머리카락 8 · 체형 6 · 스타일 8을
    조합해 **3,072가지** 중에서 고를 수 있어요.
    고른 캐릭터는 선생님 무대·내 무대·순위표에 똑같이 그려지고, 무대에서는 발밑 그림자와 함께 서 있어요.
    - 표정 **미소 · 활짝 · 윙크 · 진지 · 놀람 · 메롱 · 삐죽 · 반짝**
    - 머리 **숏컷 · 단발 · 울프컷 · 묶음 · 웨이브 · 삐죽 · 곱슬 · 포니테일**
    - 체형 **아담 · 슬림 · 보통 · 듬직 · 통통 · 키다리**
    - 스타일(상의+하의+신발 세트) **후드+조거 · 셔츠+베스트 · 멜빵데님 · 야구점퍼 · 트레이닝 · 가디건+치노 · 스트라이프 · 아노락**
    - 성별을 고정하지 않는 중성적인 톤이라 반 아이 누구나 부담 없이 고를 수 있어요.
    - 내 캐릭터는 무대에서 빛나는 발밑 링 + `나` 표시로 또렷하게 구분돼요.
- ⚡ **실시간 P2P**: 선생님 브라우저가 방장이 되고, 학생들은 [PeerJS](https://peerjs.com)(WebRTC)로
  직접 연결됩니다. (최대 40명)
- ✏️ **문제 관리**: 기본 5문제가 들어 있고, 추가·수정·삭제한 문제는 브라우저(localStorage)에 저장됩니다.

## 사용 방법

1. 선생님: **👩‍🏫 선생님 → 방 만들기** → 화면의 QR/링크를 학생에게 보여 줍니다.
2. 학생: 링크를 열면 코드가 자동 입력됩니다. 이름(한글 OK)과 내 캐릭터를 고르고 입장!
3. 선생님: 제한시간(없음·10·15·30초)을 고르고 **출제하기** → 학생 이동 → **정답 공개**(정답자 +10점)
4. **다음 문제** → 반복, **순위표**로 결과 확인

## 파일 구성

| 파일 | 설명 |
